Entry for the [make.fun](https://make.fun/c/u-boothlord-one-line-to-your-younger-self-22e97f76) bounty **One Line to Your Younger Self** — write the single line you would send your younger self if one line were all you got.

## The line

> Kid, the scar you hide under your sleeve becomes the map someone else follows home — wear it where they can see it.

## How it works

`main.py` writes that one line (115 characters, a single sentence, in English) to `/output/entry.txt`:

```sh
python3 main.py
```

The gate checks `/output/entry.txt` is UTF-8 text of 1 to 200 characters; this entry is 115 characters including its final newline, one line, one sentence.
